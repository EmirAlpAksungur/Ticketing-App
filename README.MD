Bu uygulama, mikroservisler ile ölçeklenebilir uygulamalar inşa etme üzerine geliştirilmiştir. Event tabanlı iletişim, Docker ve Kubernetes ile dağıtım ve React, Node, Express gibi teknolojilerle full-stack sistemler oluşturma konularına odaklanmaktadır.

Özellikler:
- Frontend: Ticket verilerini görüntülemek için Hooks ve Next.js kullanan Server-Side Rendered (SSR) React uygulaması.
- Backend: Ticket yönetimi ve asenkron olayları işlemek için Node.js ve Express tabanlı mikroservis mimari.
- Veritabanı: Ticket bilgilerini saklamak için MongoDB.
- Kimlik Doğrulama: Ticket API'lerine erişimi yönetmek için JWT tabanlı kimlik doğrulama.
- Dağıtım: Ölçeklenebilir dağıtım için Docker konteynerlerinde çalışan Kubernetes kümesi.
- Event Tabanlı İletişim: Servisler arası veri iletişimini yönetmek için özel bir event bus.


Kullanılan Teknolojiler:
- Frontend: React, Next.js, React Hooks
- Backend: Node.js, Express
- Veritabanı: MongoDB, Redis
- Dağıtım: Docker, Kubernetes
- Kimlik Doğrulama: JWT
